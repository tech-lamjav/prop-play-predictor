Primary action button for Smart Betting — forest green primary, amber accent CTA; use inside light rebrand surfaces.

```jsx
<Button variant="forest">Abrir análise completa</Button>
<Button variant="amber" trailingIcon={<ArrowRight size={16} />}>Ver oportunidades</Button>
<Button variant="outline-forest" size="sm">Filtrar</Button>
```

Variants: `forest` (primary), `amber` (accent CTA on light), `amber-bright` (CTA on the dark forest hero), `outline-forest`, `secondary` (white + hairline border), `ghost`, `link`, `destructive`. Sizes: `sm` (36px), `default` (40px), `lg` (44px), `icon` (square). Radius is 10px (`--radius-md`).
